هم هم پنل است و هم خود تونل:

پنل روی /dash — ساخت کانفیگ VLESS، حجم، روز، QR، ربات تلگرام، بکاپ
تونل روی همان ورکر — کلاینت به دامنهٔ ورکر وصل می‌شود؛ ماشین دومی در کار نیست
داری	لازم نیست
VLESS روی WebSocket و TLS	VPS
پنل فارسی، روشن / تاریک، موبایل	توکن API کلادفلر
ربات تلگرام برای ادمین	Wrangler یا package.json
لینک ساب (هر آی‌پی = یک کانفیگ)	چیزی جز D1
نیست: VMess، Trojan، OpenVPN، WireGuard، پروکسی تلگرام. این‌ها روی ورکر سرور زنده نمی‌شوند.

چطور کار می‌کند؟
text

موبایل / کامپیوتر  --VLESS WS/TLS-->  دامنهٔ ورکر تو
                                          │
                                          ├─ پنل     /dash
                                          ├─ استتار   /      → شبیه ubuntu.com
                                          └─ تونل     /vpnws → وصل به سایت مقصد
                                               در صورت نیاز از آی‌پی‌های تیک‌خورده
آدرس داخل لینک VLESS همیشه دامنهٔ ورکر است (یا ورکر پشتیبان). آی‌پی به‌عنوان سرور نوشته نمی‌شود.
بعد از وصل، ورکر اول خود سایت را می‌زند؛ اگر لازم شد از آی‌پی‌هایی که در تنظیمات تیک زده‌اید دوباره امتحان می‌کند (برای سایت‌هایی که خروجی کلادفلر را می‌بندند).
ساب یک لینک است. هر آی‌پی که تیک بزنید = یک کانفیگ داخل همان لینک. خط اول ساب مصرف، مانده، زمان را نشان می‌دهد و با هر بروزرسانی در اپ عوض می‌شود.

خروج بعد از ۲ ساعت بیکاری؛ «مرا به خاطر بسپار» = ۷ روز

حجم، روز، سقف دستگاه، سقف سرعت، اسم ۵ کاراکتری تصادفی
خروجی CSV، بکاپ JSON، سلامت دامنه‌های پشتیبان
استتار: آدرس خالی دامنه شبیه اوبونتو است و در تنظیمات عوض نمی‌شود

راه‌اندازی
فقط از داشبورد کلادفلر استفاده کنید. Node و Wrangler لازم نیست.

۱. ورکر
وارد dash.cloudflare.com شوید
Workers & Pages → Create Worker
یک اسم بگذارید (مثلاً ham) → Deploy
Edit code → کد نمونه را پاک کنید → کل فایل 

ham.js
 را پیست کنید → Save and Deploy
Settings → Compatibility date را روی 2024-09-01 یا جدیدتر بگذارید
(قدیمی‌تر باشد سوکت TCP نیست؛ وصل می‌شود ولی اینترنت باز نمی‌شود)
۲. دیتابیس
Workers & Pages → D1 → Create database (مثلاً ham-db)
ورکر خودتان → Settings → Bindings → Add → D1 Database
Variable name باید دقیقاً این باشد:
text

DB
سه حرف بزرگ. نه db نه اسم دیگر.

دیتابیس را انتخاب کنید → Save → دوباره Deploy
بدون DB ویزارد جلو نمی‌رود. تا Deploy نشود وصل نیست.

۳. ویزارد
در مرورگر:

text

https://YOUR-WORKER.YOUR-SUBDOMAIN.workers.dev/dash
مرحله	چه وارد کنید
دیتابیس	باید وصل باشد. اگر نه: اسم متغیر DB نیست یا Deploy نشده
مدیر	رمز دو بار (حداقل ۸ کاراکتر). نام کاربری نیست. کد بازیابی ۸ کاراکتری را یادداشت کنید. ایمیل اختیاری است
تلگرام	توکن از @BotFather و Chat ID عددی از @userinfobot. نمی‌شود رد کرد
ریشهٔ دامنه (/) استتار است، پنل نیست. همیشه /dash را باز کنید.

توکن API کلادفلر در این پنل وجود ندارد.

۴. اولین فیلترشکن
فیلترشکن → جدید → اسم ۵ کاراکتری را نگه دارید یا عوض کنید → یک پورت (با دامنهٔ اختصاصی معمولاً 443) → حجم و روز (۰ = نامحدود) → یک آی‌پی خروجی → ذخیره.

لینک VLESS را کپی کنید یا QR را در v2rayNG، Hiddify، Streisand، v2rayN، Shadowrocket یا Clash Meta اسکن کنید.

۵. سابسکراپشن (اختیاری)
ساب → جدید → چند آی‌پی تیک بزنید → ذخیره.
۵ آی‌پی = ۵ کانفیگ داخل یک لینک. این لینک را در اپ به‌عنوان subscription وارد کنید، نه به‌عنوان یک VLESS تکی.

خط اول ساب با هر بروزرسانی: مصرف، مانده، زمان.

۶. دامنهٔ اختصاصی (پیشنهادی)
workers.dev اغلب فیلتر است.

دامنه را به همان حساب کلادفلر اضافه کنید
ورکر → Settings → Domains & Routes → مثلاً vpn.example.com
DNS از نوع CNAME، ابر نارنجی
SSL/TLS روی Full
در تنظیمات هم می‌توانید ورکر پشتیبان بگذارید (هر خط یک دامنه). لینک‌ها با آدرس اصلی پنل ساخته می‌شوند.

وب‌هوک تلگرام
با ذخیرهٔ توکن در هم، وب‌هوک معمولاً خودش ست می‌شود. اگر لازم شد دستی:

text

https://api.telegram.org/bot<BOT_TOKEN>/setWebhook?url=https://YOUR-WORKER.YOUR-SUBDOMAIN.workers.dev/hamtg
هشدار و بکاپ روزانه: ورکر → Triggers → Cron → 0 3 * * *

نکات کلاینت
مسیر پیش‌فرض /vpnws. SNI و Host = دامنهٔ ورکر یا دامنهٔ اختصاصی شما، نه یک سایت تصادفی
با دامنهٔ اختصاصی پورت 443 بهتر است
اگر سایت‌ها باز نشد: HTTP/3 (QUIC) را خاموش کنید؛ DNS را 1.1.1.1 بگذارید
1.1.1.1 و 1.0.0.1 را آدرس کانفیگ نگذارید
پینگ واقعی همان پینگ مرورگر در تنظیمات است؛ پینگ ورکر به anycast معمولاً مرده دیده می‌شود
دورزدن پیشرفته فقط وقتی اثر دارد که خود اپ Fingerprint / ECH / fragment / 0-RTT را پیاده کرده باشد
امنیت
رمز بلند + کد بازیابی + OTP تلگرام
/dash و استتار فقط آدرس را قایم می‌کنند؛ جای رمز نیستند
درخواست‌های تغییردهندهٔ پنل CSRF می‌خواهند؛ کوکی نشست HttpOnly است
توکن ربات در D1 رمزنگاری می‌شود. اگر هم فایل ورکر هم D1 لو رفت، توکن را در BotFather باطل کنید
اختیاری: در ورکر یک Secret به نام HAM_KEY بگذارید
۸ ورود غلط از یک IP → ۱۵ دقیقه قفل
آی‌پی فقط از CF-Connecting-IP خوانده می‌شود
